# Pretty Jason

Yet another pretty JSON browser extension.

## Features

- Collapsible tree with item counts; Option-click a toggle to fold or unfold the whole branch
- Light and dark modes matching system preference
- JSON, Raw, and HTTP Headers tabs
- Instant key/value and header filtering
- Clickable URLs, including root-relative paths
- Click a key to copy its path; Option-click to copy its value
- Color swatches and timestamp tooltips
- JSON Lines (NDJSON) support
- Payload size at a glance
- One-click copy
