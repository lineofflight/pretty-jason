Pretty Jason

Privacy

Effective November 24, 2026

Pretty Jason formats JSON in your browser. Line of Flight, which makes it, can’t see what you open.

No account, no tracking

There’s no account, analytics, telemetry, or ads, and no server of ours to talk to.

On your device

Parsing, formatting, filtering, and path copying happen in the tab you’re viewing. Pretty Jason reads a page only to detect and format JSON. Your theme choice (Auto, Light, or Dark) is saved in that site’s localStorage.

Response headers

Opening the Headers tab on an http: or https: page sends a same-origin HEAD request to that URL, or a GET if the server doesn’t answer HEAD, to show its response headers. Nothing is sent anywhere else.

This website

This site sets no cookies, and the home page demo sends nothing. It counts page visits with Plausible, without cookies or storing your IP address. GitHub Pages hosts it and may log visits, as web hosts do.

Changes

If this policy changes, this page will show the new version and date.
