Pretty Jason

Privacy

Effective November 16, 2026

Pretty Jason formats JSON documents locally in your browser. Line of Flight, which makes it, can’t see what you open in it.

No account, no tracking

There’s no account to create. Pretty Jason has no analytics, no telemetry and no ads, and there are no servers of ours for it to talk to.

On your device

All parsing, formatting, filtering and path copying happen locally, inside the browser tab you’re looking at. Pretty Jason reads a page only to tell whether it’s a JSON document and, if it is, to format it.

Your theme preference (Auto, Light or Dark) is stored only in that site’s local storage, in your browser.

Response headers

When you open the Headers tab on an http: or https: page, the extension makes a same-origin HEAD request to the URL you are already viewing, so it can show the server’s HTTP response headers. If the server doesn’t answer HEAD, it asks with GET instead. Nothing is sent anywhere else.

This website

This site has no cookies and no analytics. The demo on the home page runs in your browser and sends nothing. The site is hosted on GitHub Pages, and GitHub may log visits as web hosts do.
