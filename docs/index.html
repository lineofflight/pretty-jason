This is the real inspector. Fold a branch, click a key, press / to filter, switch the theme.

Fast by default

Instant collapsible trees for JSON and JSON Lines (ndjson / jsonl). Option-click an arrow to fold or unfold an entire branch. Collapsed branches still open when your browser’s own Cmd+F finds a match inside.

Click to copy paths

Click any key to copy its JavaScript accessor path (response.items[0].id). Option-click a key to copy its JSON value instead.

Zero-clutter smarts

Inline color swatches, relative-time tooltips on ISO-8601 and Unix timestamps, clickable URLs and root-relative API paths, and a lazy Headers tab.

GitHub Primer themes

Crisp light and dark palettes from GitHub Primer that follow your system appearance or lock to Auto, Light, or Dark with zero flash.

Mac, iPhone & iPad

Native Safari Web Extension for macOS, iOS, and iPadOS with a responsive mobile filter bar, plus Manifest V3 support for Chrome and Firefox.

Private by design

Runs entirely on-device with zero telemetry, zero analytics, and zero external requests.

Install

Until Pretty Jason reaches the stores, install it from the source.

  • Safari (macOS & iOS). Open safari/Pretty Jason/Pretty Jason.xcodeproj in Xcode and run the macOS or iOS app, then turn the extension on in Safari’s Extensions settings.
  • Chrome. Open chrome://extensions, turn on Developer mode, choose Load unpacked, and pick the src folder.
  • Firefox. Open about:debugging, choose This Firefox, then Load Temporary Add-on, and pick src/manifest.json.
