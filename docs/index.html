Pretty Jason

Yet another pretty JSON browser extension.

For Safari on Mac, iPhone and iPad.

Coming to the App Store

Source on GitHub
api.example.com/v1/extensions/1042

Fold a branch, click a key, press / to filter, switch the theme.

Fast by default

Instant collapsible trees for JSON, plus JSON Lines served as plain text. Option-click an arrow to fold or unfold a whole branch. Folded branches still open when your browser’s own find matches inside.

Click to copy paths

Click any key to copy its JavaScript accessor path (response.items[0].id). Option-click a key to copy its value instead.

Small touches

Inline color swatches, relative-time tooltips on ISO-8601 and Unix timestamps, clickable URLs and root-relative API paths, and a lazy Headers tab.

GitHub Primer themes

Crisp light and dark palettes from GitHub Primer. Auto follows your system, or pick Light or Dark, with no flash on load.

Mac, iPhone & iPad

Native Safari Web Extension for macOS, iOS, and iPadOS, with a responsive mobile filter bar.

Private by design

Runs on your device with no telemetry or analytics. It only talks to the server you’re already viewing, and only when you open Headers.

Install

Until Pretty Jason reaches the App Store, build it from the source: open safari/Pretty Jason/Pretty Jason.xcodeproj in Xcode and run the macOS or iOS app, then turn the extension on in Safari’s Extensions settings.
