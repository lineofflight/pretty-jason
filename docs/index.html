Pretty Jason

Yet another pretty JSON browser extension.

For Safari on Mac, iPhone, and iPad.

Source on GitHub

Coming soon to the App Store

Click a key to copy its path, option-click an arrow, or press / to filter.

Tree & search

JSON and plain-text JSON Lines. Option-click an arrow to fold a branch. Browser find still matches inside folded nodes.

Copy paths

Click a key to copy its path (items[0].id). Option-click to copy its value.

Inline details

Color swatches, relative-time tooltips on timestamps, clickable URLs and /relative paths, and on-demand HTTP headers.

Local

Runs on your device with no analytics or external requests. Follows system appearance or pins Light or Dark per site.

Install

Until Pretty Jason is on the App Store, build the Xcode project from GitHub, run the app once, and enable the extension in Safari settings.
